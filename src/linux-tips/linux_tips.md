# Linux 实用技巧

本文收集了一些 Linux 使用中的实用技巧，涵盖系统安全与电源管理等常见场景。

## 安全加固

- [Linux SSH 双因素认证](./linux_2FA.md)

  使用 Google Authenticator 为 SSH 登录添加双因素认证（2FA），显著增强远程登录的安全性。

## 电源管理

- [禁用笔记本合盖休眠](./disable_sleep.md)

  让笔记本合盖后继续运行而不触发休眠，适用于外接显示器、运行长任务或作为服务器使用的场景。

- [笔记本合盖熄屏（不休眠）](./lib_close_screen_off.md)

  在「合盖不休眠」的基础上更进一步：合上盖子只熄灭屏幕、系统照常运行，适合把笔记本当无头服务器使用。
